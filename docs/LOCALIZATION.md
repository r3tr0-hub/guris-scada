# Локализация SCADA

`ui/locales/catalog.json` определяет доступные языки, их локали и флаги. В комплекте русский `ru` / `ru-RU` и английский `en` / `en-GB`. Загрузка выполняется локально, без CDN или серверов переводов. `ui/i18n.js` читает словарь перед запуском интерфейса.

## Добавление языка

1. Скопируйте `ru.json` в новый файл, например `de.json`. Сохраняйте UTF-8 и структуру `{"schema":1,"messages":{...}}`.
2. Переведите значения `messages`. Ключи — исходные русские строки; менять их нельзя. Сохраняйте все вставки `{0}`, `{1}` и т. д. Их можно переставлять в переводе. Числа и обозначения PLC-символов не добавляйте в ключ вручную.
3. Добавьте SVG-флаг, например `ui/assets/flags/de.svg`.
4. Добавьте запись в массив `languages` каталога:

```json
{"code":"de","locale":"de-DE","name":"Deutsch","flag":"/assets/flags/de.svg"}
```

5. Откройте выбор по флагу и выберите язык. Пересобирать EXE или редактировать C/JS не требуется.

Код и имя файла должны совпадать: 2–18 латинских букв, цифр, `-` или `_`. Этот же формат используется для имени флага. Флаг обязан лежать в `/assets/flags/`. JSON должен быть корректным; дубли ключей не допускаются. Полный базовый список — `ru.json`; отсутствующий ключ оставляет исходную русскую строку. После добавления новых надписей в коде разработчик должен добавить одинаковые ключи во все словари.

## Работа интерфейса

`SCADA_I18N.t(source, [parameters])` переводит шаблон и подставляет параметры. `SCADA_I18N.text(raw)` переводит исходное сообщение основного процесса, в том числе сообщения с числами. `bind` применяет словарь к статическому HTML и атрибутам доступности/подсказок. Показ даты, календаря, группировки разрядов и десятичного разделителя использует `Intl` и локаль из каталога.

Выбор записывается через `/api/language` в `local/scada_options.json`. Настройки оформления сохраняются при смене языка и наоборот. Выбор доступен оператору, не меняет права доступа. Перезагрузка окна сохраняет текущую страницу через `sessionStorage` и продолжает существующую инженерную сессию. Серверный таймер не зависит от этой перезагрузки. При активной записи выбор языка временно недоступен.

Обычные команды Windows-трея читают тот же словарь. Системные сообщения Windows, исключительные сообщения запуска до загрузки интерфейса, PLC-символы и технические диагностические файлы не являются переводимым содержимым операторских страниц.

HTTP-сервер предоставляет только файлы с разрешённым именем из каталогов языков/флагов. Эти маршруты не позволяют читать произвольные файлы. Новые языки в дальнейшем можно перевести независимо от привязки параметров ПЛК.
