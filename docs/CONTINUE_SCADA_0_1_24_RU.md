# Продолжение разработки · 0.1.24

Авторитетная точка входа: src/fields.h (714 полей, F_ENGINEERING_FIRST=256), src/engineering_catalog.h (закрытый список полей 30 разделов), ui/engineering.json (подписи/справки/связанные показания), ui/functionality.js (общий интерфейс Функционала/Производительности/остальной инженерки). Адреса разрешаются только ADS по полному имени и проверяются по типу/размеру/версии, адреса из архивов используются лишь как доказательства разбора.

POST /api/engineering-view принимает только section из allowlist или пустую строку. Требует Engineer, обновляет подписку на 5 секунд. Первые 256 полей остаются в обычном цикле. Дополнительные метаданные разрешаются по 4 за итерацию; после страницы опрос прекращается. GET /api/state не отдаёт неактивные дополнительные поля и не отдаёт их оператору.

Регулировка обычных инженерных параметров доступна в любом состоянии машины. field_stopped теперь возвращает 0; отдельные manual_ready/engineering_ready остаются для ручных движений, групповых действий и прежней политики размотчика. Не возвращать проверку 5/9 + auto=0 на инженерные параметры. Не менять timed cleaning на свободную запись 45.

Добавлены T_TIME (4 байта, ADST_UINT32=19, миллисекунды), T_HEX12 (STRING(12), ADST_STRING=30, 13 байт с NUL). LREAL теперь поддерживает запись 8 байт. Общий буфер поля 16 байт; ADS SUM и I/O используют одинаковый stride 16. JSON raw — до 32 hex-знаков. Заводской код в JSON передаётся точным 48-битным числом; UI показывает 12 HEX-знаков и проверяет форму. Аудит использует 17 значащих цифр для сохранения LREAL/48-bit.

Не путать виртуальные dancer1Position/dancer2Position с фиксированными Salmalar.rScaledBalerin[N]. Старые виртуальные показания проверяют текущий selector до/после чтения массива. Показание тефлона выбирается по актуальному индексу из разрешённого набора прочитанных каналов, а не по попавшему в VM-разбор нулевому индексу. Дополнительные показания и уставки имеют независимое качество.

При переносе исходных настроек некоторые существующие read-only слоты назначений/лимитов/количества каналов стали инженерными уставками по доказанному обработчику HMI. Не создавать алиасы на те же имена. Идентичность фиксированных операторских каналов после переназначения по-прежнему проверяется.

Сохранены странности старого HMI: три кнопки потенциометра направлены на Salma[7]/[8], отличающиеся от числового канала страницы. Они обозначены явно. Назначение/единица rTakviyeKartGecikmeMesafe требует проверки; не конвертировать по догадке. Несогласованные диапазоны общих параметров объединены пересечением. Служебные Isilar.bList/ValveKontrol.bValveList и Windows.* не записывать как параметры.

Проверки: tests/test_release24.py — все разделы и все подтверждённые регулируемые поля, реальные API+синтетический ADS, точные байты, readback, 15 состояний машины, роли, границы TIME/точность LREAL/HEX12, плохие метаданные, конфликты, потерянный ACK, истечение подписки. tests/test_release24_browser.cjs — все разделы/справки/парные показания/клавиатуры/редактирование при работе.
