# Guris SCADA 0.1.16 · 16.10.2026

- Все три обнуления доступны при любом состоянии станка и включённом автомате. Нужны свежая связь и завершение предыдущей операции. При росте счётчика окно подтверждения показывает актуальное число и остаётся доступным. Ноль проверяется во время штатного импульса сброса; следующий пакет после снятия импульса не вызывает ложную ошибку. Прямой записи в счётчики нет, потерянный запрос не повторяется.
- В выкидных валах скорость и синхронизация расположены в одной колонке, с одинаковыми полями ввода. В приёмном вале увеличена высота строк, исправлен выход содержимого за границы, у расчётной скорости убрана подпись шт/мин.
- Добавлена плитка Jog и пустая страница для будущих инженерных настроек ручного хода. Параметры в неё пока не добавлялись.
- Из нижней части боковой панели убраны TEST с номером версии, кнопки журнала записей и опций. Аварии опущены вниз. Журнал изменений остаётся в Опциях SCADA.
- Аварии открываются полноценной страницей. Список прокручивается, есть кнопки прокрутки, подтверждения и очистки истории. Очистка по-прежнему требует подтверждения; активные причины она не устраняет. Иконка аварий мигает красным при свежих активных записях или аварийном состоянии станка.
- Вверху аварий — переход во Входы/выходы. Пять страниц входов и три выходов повторяют состав штатного HMI: сопоставлены все 241 строки. Общий каталог содержит 872 элемента образа I/O и 11 вычисленных показаний HMI; есть поиск, фильтр и страницы по 48 строк. Дискретные 0/1 показываются красным/зелёным, отсутствие свежих данных — серым прочерком. Аналоговые каналы показывают исходные числовые значения образа I/O. Управления выходами здесь нет.
- Диагностика использует тот же последовательный ADS-обмен: адреса определяются по именам, только видимые сигналы читаются раз в 500 мс, поиск не более двух новых имён за цикл. При выходе со страницы подписка снимается; без продления она истекает через 2,5 секунды. Основной опрос счётчиков остаётся 100 мс, параметров — 500 мс.

Раздел Мануалы пока не создавался: по запросу пользователя сначала предложены Markdown с фотографиями, Word с импортом и PDF. Рекомендуемый формат — папка на гайд с Markdown и изображениями, общий вид и поиск в SCADA. Реализация, кнопка открытой книги и анимация перелистывания ожидают выбора формата.

Список Jog, доказательства I/O и исследование светофора/звука: **JOG_IO_TOWER_0_1_16_RU.md**. Найдены 18 настроек Jog с полями ввода HMI, ещё 15 числовых параметров объявлены в TPY. Выходы светофора и звука установлены; произвольное управление ими требует предусмотренного в ПЛК запроса, поскольку текущая программа сама записывает выходы каждый цикл. Команд/форсирования светофора в сборке нет.

Обновление: завершить прежнюю SCADA, распаковать весь архив в новую папку на диске, перенести прежние connection.json и весь каталог local, запустить Start_Compatibility.cmd. Темы, локальная авторизация, таймеры восстановления и инженерные ограничения других настроек сохранены.
