# Guris SCADA 0.1.31 — единое управление анимациями меню

У встроенных копий 12 SVG удалены автономные media-правила prefers-reduced-motion, принудительно отключавшие CSS-анимации независимо от настроек SCADA. Теперь они, как остальные механизмы интерфейса, подчиняются общему переключателю «Анимации». При ВЫКЛ движение приостанавливается, при ВКЛ работает и при системном reduced-motion. Скрытие страницы/окна по-прежнему приостанавливает анимации.

Оригиналы в ui/assets/menu-v16 не изменены. Размеры и расположение иконок сохранены. Параметры запуска Edge и режим совместимости с отключённым GPU не изменены.

Пользователь сообщил, что только новые SVG стоят в Start_Compatibility, но работают в Start_Browser. В локальном чистом Edge киоске сам --disable-gpu не остановил SVG. Отдельная политика reduced-motion воспроизводит выборочное отключение новых SVG; наличие именно этого условия у пользователя не измерено, поэтому окончательное устранение его случая требует повторной проверки на его запуске.

Проверки: JSDOM/CSS; Linux backend через WSL; Playwright 12 SVG после потери связи, три темы и два разрешения, границы, выключение анимаций и повторное включение при reduced-motion. Windows Edge запущен отдельным процессом с реальными --kiosk --edge-kiosk-type=fullscreen --disable-gpu без Playwright launch-флагов; через CDP включён reduced-motion: нож движется (9 разных кадров), при ВЫКЛ состояние paused. Проверено 10 тестов конфигурации и упаковки. Штатная Windows x64 сборка Zig 0.13.0; ZIP CRC и SHA256.

Полный backend/C-набор повторно не запускался: логика backend не менялась. Реального ПЛК и физической приёмки не было. Update не содержит рабочего connection.json и local.
