# SCADA 0.1.23 — уставка и факт рядом, общая чувствительность края

## Производительность

Исправлено размещение фактических показаний: они находятся в одной строке со своей уставкой. Белое поле «Задание» открывает экранную клавиатуру; жёлтое «Факт» показывает отдельную переменную ПЛК и не редактируется. Нажатие на подпись «Факт» открывает его описание. Всего 25 строк настроек и три вложенных показания; отдельных строк для этих показаний нет. Оба инженерных списка сохраняют непрерывную прокрутку свайпом.

| Настраиваемый параметр | Фактическое/расчётное показание рядом |
|---|---|
| Начало подачи плёнки — `feedStartSet` | `x_CENE.lrMerdaneStartPos` |
| Окончание подачи плёнки — `feedStopSet` | `x_CENE.lrMerdaneStopPos` |
| Задержка остатка рулона при максимальной скорости — `perfLowMaterialTime` | `Slow_Task.rMalAzaldiSuresi` |

Факт не копируется из уставки. Например, рядом с базой 2 с может отображаться рассчитанное ПЛК время 2,4 с. При недоступности фактического значения выводится прочерк; уставка продолжает показываться по своей достоверности. Белые и жёлтые поля различаются в тёмной и классической темах.

## Краевой контроль → Чувствительность

Одна общая настройка над карточками датчиков. Исходное имя: **Side Control Dead Zone (mm)**. Переменная: `.stKaliciData.rKenarKontrol_OluBolge`, тип `REAL` (4 байта), диапазон штатного HMI **0,1…10 мм**. Она доступна оператору и инженеру через обычную цифровую клавиатуру, включая дробные значения.

Это зона нечувствительности по отклонению, а не скорость привода или таймер реакции. Меньше число — контроль реагирует на меньшее отклонение; больше число — допускает большее отклонение. В `KenKontrol.Kontrol` одна и та же уставка передаётся `FbKenKontrol[1..4].LrOluBolgeGenislik`. В `fb_KenarKontrol` модуль ошибки положения сравнивается с этим порогом; внутри зоны автоматические запросы влево/вправо снимаются. В нашей странице остаются три существующие карточки датчиков и одно общее поле чувствительности.

Настройка читается из ПЛК. Значение 0,5 на фотографии не присваивается автоматически при установке. Действуют проверка типа, размера, доступа metadata ADS, актуальности конфигурации каналов, конфликта со штатным HMI и обратное чтение. После потери подтверждения запись не повторяется автоматически.

Состав backend: 256 полей, 175 скалярных настроек, 19 команд. Роли, временные режимы, команды движения и прежние ограничения сохранены.

## Установка

Закройте прежнюю SCADA через трей → «Выход». Распакуйте новую сборку в отдельную папку, сохраните старую как резервную копию. До первого запуска перенесите свои `connection.json`, весь каталог `local` и собственные мануалы. Запускайте **Start_Compatibility.cmd**.

Подробные доказательства параметра: `EDGE_SENSITIVITY_EVIDENCE_0_1_23.json`. Проверки выпуска: `VALIDATION_0_1_23_RU.md`. Windows GUI и реальный станок здесь не запускались.
