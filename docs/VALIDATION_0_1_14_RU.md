# Проверка Guris SCADA 0.1.14 · 16.10.2026

Пройдены 79 проверки Python на локальном имитаторе ADS, 4 набора C и 11 проверок интерфейса. Windows x64 GUI EXE собран Zig 0.13.0 без предупреждений. Реальное выполнение Windows GUI и обмен с ПЛК станка здесь не проводились.

Семь новых проверок backend: тёмная тема по умолчанию и первоначальный HTML; сохранение классической после перезапуска/смены языка/профиля; миграция прежних файлов опций; сохранение темы запросами прежнего формата; отклонение неизвестных имён и типов; отказ записи без изменения действующей темы; неизвестная тема в файле без сброса остальных опций. В этих сценариях команд записи в ПЛК нет.

Новая проверка интерфейса: выбор инженером, 23 назначения навигации, обе экранные клавиатуры, отсутствие автоматического открытия PIN, исходные цвета отсутствия связи и ADS non-RUN, смена палитры остановленных Canvas, язык/перезагрузка/выход из профиля, разрешения Full HD и 4K. Проверен возврат прежней тёмной палитры и геометрии основных полей. Исходные style.css и mockup.css совпадают с выпуском 0.1.13 побайтово.

Повторно пройдены прежние проверки backend: поля/метаданные и команды, авторизация/PIN, лента/размотчик, восстановление журналов, ограничения записи, карты HMI. Пройдены прежние проверки интерфейса: меню, анимации, температуры, ввод, привязки и команды, роли, языки, счётчики, About/Exit и плотность изображений до DPR 3. C-проверки охватывают часы ленты/размотчика, запуск окна и начальный HTML с комбинациями двух тем и двух режимов запуска.

Ручной визуальный просмотр выполнен для главной, температур, меню, настроек, часов и PIN. Браузерные снимки использованы для внутреннего QA и в архив не включены. Исходные фотографии в архив также не входят.

Подробные результаты, версии и контрольные суммы: ../BUILD_INFO.json. Текущая карта ПЛК PARAMETER_BINDINGS.json не менялась: 166 полей, 111 различных полей интерфейса, 91 скалярная настройка и 18 команд.
