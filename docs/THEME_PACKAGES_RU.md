# Пакеты тем 0.1.26

Добавьте `ui/themes/<id>.json`, затем откройте «Опции SCADA» заново. Код C/JS и общий CSS менять не требуется. Пример третьей темы: `ui/themes/forest.json`.

Плоский JSON содержит id (латинские строчные буквы, цифры, дефис), nameRu/nameEn/nameTr, description, scheme (dark/light) и свойства --sc-*. Значения — HEX-цвета, прозрачность или числовые размеры. Пакет не содержит исполняемый CSS, JavaScript, URL или внешние зависимости. Общие правила компонентов находятся в themes.css/style.css; `scheme` определяет контраст светлой/тёмной поверхности. Миниатюра строится из цветов пакета. Шрифт выбирается отдельно и не сбрасывается темой.

ID сохраняется в local/scada_options.json. Недоступный или повреждённый пакет даёт встроенную тёмную палитру. Перечень обновляется при открытии настроек, максимум 64 пакета, файл до 14КБ, не более 128 свойств. Имена пакетов не позволяют обход каталога; символьные ссылки и исполняемые значения отклоняются.

## Разделение палитры и геометрии с 0.1.27

Размеры, сетки, прокрутка и типографика общие для всех тем: `style.css`, замороженная база узлов `mockup.css`, стили мануалов и производства. `themes.css` задаёт только общие смысловые роли поверхностей, текста, фокуса и состояний; в нём нет ветвей по имени/схеме темы и изменений компоновки. Новые пакеты не требуют изменений C/JS.

Пары для обычного текста: `--sc-text`/`--sc-panel`, `--sc-muted`/`--sc-panel`; для полей: `--sc-field-ink`/`--sc-field`, `--sc-field-muted`/`--sc-field`. Выбранные действия используют `--sc-primary-text`/`--sc-primary-bg`, фактические показания — `--sc-reading-text`/`--sc-reading-bg`. Отдельные `--sc-header-*` и `--sc-component-*` задают контраст шапки и навигации. Инженерная сетка поддерживает `--sc-engineering-bg`, `--sc-engineering-top`, `--sc-engineering-text` с откатом на общие цвета.

`--sc-line` задаёт границы/разделители, `--sc-cyan` — акцент/фокус; зелёный, янтарный и красный — известные состояния. Неизвестность отображается нейтральной поверхностью и текстом, а не цветом выключения/аварии. Отключение действия не означает плохое качество данных. Числовые декоративные значения старых пакетов допустимы форматом, но не должны использоваться для размеров элементов. В текущих компонентах размеры от пакета не зависят.

`npm test --prefix tests` проверяет CSS-контракт и основные контрастные пары трёх поставляемых пакетов. Полный браузерный визуальный прогон: `python3 tests/run_browser.py test_theme_visual_browser.cjs` после сборки Linux backend; `SCADA_QA_DIR` задаёт папку PNG. Прогон использует только loopback peer.
