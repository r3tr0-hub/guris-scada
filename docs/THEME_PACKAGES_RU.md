# Пакеты тем 0.1.26

Добавьте `ui/themes/<id>.json`, затем откройте «Опции SCADA» заново. Код C/JS и общий CSS менять не требуется. Пример третьей темы: `ui/themes/forest.json`.

Плоский JSON содержит id (латинские строчные буквы, цифры, дефис), nameRu/nameEn/nameTr, description, scheme (dark/light) и свойства --sc-*. Значения — HEX-цвета, прозрачность или числовые размеры. Пакет не содержит исполняемый CSS, JavaScript, URL или внешние зависимости. Общие правила компонентов находятся в themes.css/style.css; `scheme` определяет контраст светлой/тёмной поверхности. Миниатюра строится из цветов пакета. Шрифт выбирается отдельно и не сбрасывается темой.

ID сохраняется в local/scada_options.json. Недоступный или повреждённый пакет даёт встроенную тёмную палитру. Перечень обновляется при открытии настроек, максимум 64 пакета, файл до 14КБ, не более 128 свойств. Имена пакетов не позволяют обход каталога; символьные ссылки и исполняемые значения отклоняются.
