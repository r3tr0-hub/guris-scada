# SCADA 0.1.22 — производительность и списки инженерных параметров

## Изменения

- **Меню → Опции → Производительность** вместо заглушки PERFORMANS. Перенесены все 25 настроек трёх исходных экранов и три показания ПЛК. Названия переведены, исходное имя HMI оставлено под названием.
- Нажатие на название открывает разбор параметра, исходное имя, символ ПЛК, текущее значение и диапазон. Ввод числа открывает существующую цифровую клавиатуру.
- «Функционал» содержит все 62 параметра в едином списке. Четыре вкладки OPSIYONLAR удалены; прокрутка пальцем или колесом. «Производительность» устроена так же.
- Оба инженерных раздела видит только инженер. Изменения в новом разделе разрешены на остановленной линии, состояние 5/9 и auto=0. Запись проверяется backend до очереди и непосредственно перед отправкой; результат подтверждает чтение из ПЛК.
- 255 читаемых полей, 174 скалярные настройки, 19 отдельных команд. Шесть существовавших привязок использованы без дублирования символов; инженерный максимум длины отделён от рассчитанного ПЛК предела главной страницы.
- RU/EN/TR: русские пояснения, английские переводы; турецкий режим сохраняет исходные названия HMI для сверки.

Полный разбор: **PERFORMANCE_PARAMETERS_RU.md**. Неоднозначные заводские названия и отсутствующие единицы не заменены догадками. Программные верхние границы трёх дистанций помечены отдельно от границ HMI.

## Установка

1. Закройте текущую SCADA через трей → «Выход».
2. Распакуйте весь архив в новую папку на диске. Сохраните прежнюю папку как резервную копию.
3. До первого запуска скопируйте свои `connection.json`, весь `local` и собственные мануалы из предыдущей сборки. Не копируйте поверх новые `src` и `ui` старые файлы.
4. Запустите **Start_Compatibility.cmd**. Войдите инженером и откройте **Меню → Опции → Производительность**.

Новая версия не присваивает настройкам значения с фотографий и не записывает настройки при входе на страницу.

Windows GUI и физическое действие на станке здесь не испытывались. Состав локальных проверок указан в **VALIDATION_0_1_22_RU.md**.
