# Проверка Guris SCADA 0.1.27

Дата: 30.10.2026. Среда: Windows x64, Zig 0.13.0; Linux-проверки — WSL `GurisSCADA-Dev` (Ubuntu 24.04). Реальный ПЛК не использовался.

| Linux C11 backend | Успешная сборка с включёнными -Wall/-Wextra/-Wpedantic, OpenSSL development |
| 8 C-наборов | PASS: очистка, размотчик, Edge CLI, bootstrap, production time, material policy v2, смены, diagnostic recorder |
| JSDOM/CSS `test_ui.cjs` | PASS: значения, запись, неизвестность, диапазоны, конфликты, меню и клавиатура |

| `test_release_connection.py` через WSL | 10/10: упаковка Update/Configured/OfflineSetup, сохранение байтов подключения, запуск и перезапуск |
| `test_themes.py` через WSL | 9/9: роли, сохранение и перезапуск, повреждённые настройки, динамическое добавление пакета, отклонение опасных значений |
| `test_release24_browser.cjs` | PASS: все 30 инженерных разделов, реальные локальные TIME/HEX12 редакторы, подтверждение, роли, подписки |

| `test_theme_visual_browser.cjs` | PASS: 28 страниц × 2 темы; все 30 инженерных разделов в обеих темах; геометрия при переключении; отсутствие перекрытий в краевом контроле; нейтральная неизвестность; видимые canvas-иконки |

Браузерная матрица сохранена в `build/validation/theme-visual-final/`: 278 PNG и `results.json`. Снимки просмотрены через сводные листы `review/final-00.jpg` … `final-13.jpg`; ключевые экраны дополнительно просмотрены в полном размере. После уточнения ширины колонки часов и нейтральных состояний фотометки выполнен отдельный повторный прогон ключевых страниц (138 снимков) в `build/validation/theme-followup/`. Это локальные изображения с синтетическими данными, не производственные отчёты.

В матрице использованы разрешения 1024×600 (логический экран панели из проекта) и 1920×1080; состояния без связи и с данными loopback peer; оператор и инженер на доступных им страницах; системный шрифт и Verdana. Дополнительно выполнена проверка с увеличением букв на 20% на главной, ленте, меню, краевом контроле, входах/выходах, актуаторах, фотометке, опциях SCADA и инженерном меню. Это тестовая модификация DOM, не новая настройка размера шрифта в приложении.

Диалоги ввода числа, подключения, языка и помощи фотометки открывались штатными действиями. Для визуального обзора остальных оболочек (PIN/роль/пароль, история, подтверждения, фото, помощь и HEX-клавиатуры) использовалось принудительное отображение локального DOM без нажатия подтверждающих кнопок. Полный набор бизнес-состояний каждого диалога не проверялся одним визуальным тестом; действующие сценарии редакторов/подписки проверялись отдельными браузерными тестами. Подтверждений выполнения команд на реальном станке нет.

Визуальный прогон не отправил ни одной команды записи даже в loopback peer. Другие интеграционные сценарии проверяют разрешённые записи только на локальном имитаторе.

Проверка `test_release_connection.py`, первоначально запущенная Windows Python против Linux ELF, получила WinError 193 для четырёх сценариев запуска; весь набор затем успешно выполнен в WSL. Это не пропущенные проверки.

## Сборка и приёмка

Windows EXE собирается штатным `tools/build_windows.py` с Zig 0.13.0, Update — `tools/build_release.py`. Проверяются PE32+ AMD64 GUI, CRC ZIP, все SHA256 обязательных EXE/UI-файлов, исходный fingerprint и связь BUILD_INFO с Git. В Update отсутствуют runtime `connection.json`, `local/`, рабочие БД, журналы и свои мануалы.

Для Windows успешно выполнен локальный запуск финального EXE 0.1.27 с отключённым примером подключения: собственный Edge сообщил UI READY, backend оставался без связи, сохранял снимок JSON и диагностический ZIP; нормальный выход завершил принадлежащий ему Edge. Результат выполнения и пути артефактов находятся в `build/validation/windows-native27-results.json` и `build/validation/release-verification.json`.

Не выполнены: физическая сенсорная панель КП4, её масштабирование Windows/DPI и доступные шрифты, касание/длительное удержание/краевые жесты, CerHost и фактическая приёмка в цехе. Локальная эмуляция касания Playwright не заменяет эту проверку. Связь и команды реального ПЛК не выполнялись и не требуются для исправления оформления.
