# Guris SCADA 0.1.13 — изменения по проверке на станке

## Контроль остатка материала на размотчике

Обычный режим — автоматическая остановка по датчику включена. Кнопка **«Отключить на 5 мин»** снимает контроль и запускает отсчёт 5:00 в основном процессе SCADA. Кнопка меняется на **«Включить сейчас»**. Повторное выключение не продлевает уже запущенный таймер.

По окончании времени SCADA запрашивает включение и проверяет ответ ПЛК. На странице размотчика видны отсчёт, фактическое состояние и сообщение; временное или бессрочное отключение также отображается в строке состояния при переходе на другие страницы.

**«Отключить бессрочно…»** доступно только инженеру при остановленном станке и требует отдельного подтверждения. Этот режим переживает перезапуск. Включить контроль обратно может и оператор обычной кнопкой. Включение с оригинального HMI также отменяет бессрочный режим.

При перезапуске сохраняется оставшееся время, а не новые пять минут. Просроченное отключение возвращается во включённое состояние после связи с ПЛК. Отключение с HMI при работающей SCADA запускает такой же временный режим. Отключённое состояние без действующего журнала при старте возвращается в нормальный контроль.

Закрытие окна в трей оставляет таймер работающим. Штатный «Выход» пытается включить временно отключённый контроль перед завершением. При отсутствии связи, остановленном ПК или недоступном ПЛК команда не может быть доставлена; задание остаётся до следующего запуска/подключения. Это таймер SCADA, а не изменение программы или защиты ПЛК.

## Остальные изменения

| Замечание | Что изменено |
|---|---|
| Продольный шов | Подпайщик в схеме плавно опускается при включении и поднимается при выключении, в том числе на остановленном станке. При выключенных анимациях сразу показывается нужное положение. |
| Вход в SCADA | Выбор инженера и открытие диалога под инженером не открывают клавиатуру. Нажмите на поле пароля. Это действует и при открытии смены пароля. |
| Текущая пачка | Добавлено подтверждаемое обнуление, как у двух остальных счётчиков. Используется штатная `MAIN.bAdetReset`, без записи в само значение счётчика. |
| Выход | Исправлена привязка к окну Edge: номер версии в заголовке больше не используется. У SCADA отдельный профиль текущего запуска и собственная группа процессов; закрываются её процессы Edge. Повторные нажатия не отправляют запросов после завершения. |
| Расположение выхода | Кнопка находится внизу страницы «Часы». В «Опциях SCADA» есть переключатель видимости; по умолчанию кнопка видна. Выход из трея остаётся доступен. |
| Отчёт | Кнопка сохранения диагностики находится в «Опциях SCADA». |
| Логотип SCADA | Открывает страницу «О программе»: назначение, фактический стек, схема обмена, версия, разработчик Авсаркисов Д.А. и wizzigun@gmail.com. Главная доступна в боковом меню. |
| Выделение и перетаскивание | Изображения и текст интерфейса не выделяются и не перетаскиваются. Поля ввода сохраняют обычное редактирование. |
| Краевой контроль | Значение конфигурации каналов 0 больше не скрывает данные исходной трёхканальной страницы. При 1–4 учитывается число каналов; неизвестная конфигурация остаётся недоступной. |
| Клей | В обычном режиме оставлен коэффициент подачи. Рабочая дистанция и дистанция без клея показываются в режиме фотометки, по одному редактору каждого поля. |
| Опции | Добавлена сетка 31 кнопки по инженерному меню с фотографии. Названия сохранены без перевода; кнопки открывают заглушки без команд ПЛК. «Опции» видны только инженеру. |

Стек текущей сборки: нативный процесс C11 под Windows, ADS/TCP, локальный HTTP; интерфейс HTML/CSS/JavaScript с SVG/Canvas; Microsoft Edge в режиме киоска. Локальные настройки, PIN и журналы обслуживает основной процесс. Основная программа станка выполняется в ПЛК.

## Обновление

1. Завершите предыдущую SCADA через трей → «Выход».
2. Распакуйте весь архив в новую папку на локальном диске.
3. До первого запуска скопируйте из предыдущей папки `connection.json` и весь каталог `local`, если они есть. Не удаляйте журналы незавершённых возвратов/снятия команд.
4. Запустите **Start_Compatibility.cmd**.

В SCADA: «Меню → Размотчик» — режимы контроля; «Меню → Опции SCADA → Оформление → Кнопка выхода» — видимость выхода; нажатие на дату/время — «Часы»; нажатие на логотип — «О программе».

Привязки остаются по именам и актуальным метаданным ADS. Новая сборка содержит 166 полей backend и 18 отдельных команд; полная карта — `docs/PARAMETER_BINDINGS_RU.md` и `docs/PARAMETER_BINDINGS.json` внутри архива.

Проверки выполнены на локальном имитаторе ADS, в Chromium и отдельными проверками времени. Windows x64 EXE собран без предупреждений. Реальная запись новых сценариев в ПЛК и работа Windows/Edge на ПК станка здесь не проверялись.
