# Проверка SCADA 0.1.13 · 16.10.2026

Пройдены 72 проверки Python на локальном ADS peer, 4 набора C и 10 проверок интерфейса. Windows x64 GUI EXE собран без предупреждений; импорты CNG, Win32 Job и часы проверены в PE. Реальный ПЛК и Windows GUI здесь не запускались.

Проверены 166 имён/типов/размеров по TPY, источник `MAIN.bAdetReset` по обработчикам HMI, все прежние скалярные настройки и закрытие общего API для режима размотчика. Проверены 3 штатных сброса с обратным чтением, исходная конфигурация краевого контроля 0 и ограничения 1–4.

Новые 11 проверок backend: временное отключение/включение и отсутствие продления; сохранение срока; просроченный журнал; потеря ACK без повторного отключения; постоянный режим и роль; неизвестный/повреждённый журнал; другой адрес ПЛК; нормальное включение при старте; завершение процесса с восстановлением; видимость выхода и совместимость прежних опций; текущая пачка. Проверка C отдельно охватывает точную границу 300 секунд, перезапуск, откат часов, HMI, offline и выход.

Проверки интерфейса: новый About, стек/автор, отсутствие выделения/drag, часы и настраиваемый Exit, намеренный вход в PIN, 31 инженерная кнопка без перевода/команд, состояние краевого контроля, дистанции клея только по фотометке, движение подпайщика на остановке и его итоговое положение, новый сброс и один запрос выхода. Повторно проверены старые настройки, языки, рисунки меню, пульс, киоск, роли, пароль, уведомления и таймер ленты. Сохранена проверка плотности/размеров до 4K/DPR 3.

Сценарий завершения backend проверен на Linux-версии того же кода. Управление своим окном/группой Edge скомпилировано для Windows и проверено по импортам; его фактическое выполнение на Windows ещё не подтверждено. Отсутствие связи не позволяет таймеру доставить включение — журнал сохраняет восстановление. Фотография и браузерные снимки использованы только для анализа и QA и в архив не включены.

Подробные результаты и SHA-256: BUILD_INFO.json. Карта: PARAMETER_BINDINGS.json. Предыдущие описания VALIDATION_0_1_11_RU.md и DISPLAY_0_1_12_RU.md относятся к указанным выпускам.
