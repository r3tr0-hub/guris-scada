# Guris SCADA 0.1.30

Исправлена остановка анимаций меню без связи с ПЛК: удалено старое принудительное CSS-правило паузы для неизвестного оборудования. Иллюстрации независимы от показаний машины; переключатель анимаций, скрытие страницы и reduced-motion сохранены.

По уточнению пользователя приёмный вал использует feeding.svg. Теперь в меню 12 новых SVG. Иллюстрации увеличены с высоты 46 до 90 CSS px (до масштабирования интерфейса), расположены на слое под подписями внутри карточек. Геометрия и действия кнопок сохранены.

Проверки: JSDOM/CSS; Linux backend через WSL; Playwright для трёх тем и двух разрешений, границ карточек, фактического движения всех 12 SVG при потере связи, паузы и reduced-motion; 10 тестов упаковки подключения. Windows x64 собирается штатным скриптом на Zig 0.13.0, ZIP проверяется по CRC и SHA256.

Полный набор backend/C-тестов повторно не запускался: функциональность backend не менялась. Приёмка на физическом станке и сенсорном экране не выполнялась. Реальных подключений и команд не было. Update не содержит рабочего connection.json и local.
