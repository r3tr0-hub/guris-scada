## Границы проверки

Для workflow первый фактический прогон произойдёт после загрузки репозитория. Реальный ПЛК для этих проверок не использовался; приёмка инженерных параметров на станке остаётся отдельным этапом.

Таблица `docs/releases/0.1.24/BUILD_INFO.json` описывает исходный выпуск. Новый упаковщик создаёт собственный `BUILD_INFO.json` для каждого ZIP и пересчитывает диагностику по реально собранным файлам.
