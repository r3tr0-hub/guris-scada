# Проверка Guris SCADA 0.1.21

Сборка: Windows 10/11 x64, C11, Zig 0.13.0, встроенная SQLite. Сборка EXE с `-Wall -Wextra -Wpedantic` завершилась без предупреждений. Проверен PE32+ GUI и список системных импортов. Запуск Windows GUI и испытания на физическом станке здесь не выполнялись.

## Автоматические проверки

- **147 Python-тестов — успешно.** Реальный C backend, локальный HTTP и имитатор ADS на loopback. Полный итоговый прогон: 253.636 с.
- **7 C-наборов — успешно:** таймеры ленты и размотчика, запуск/конфигурация интерфейса, bootstrap, монотонный учёт производства, причины простоев, границы смен и DST.
- **8 наборов интерфейса — успешно:** JSDOM/CSS; меню; привязки; ручные команды и аварии; производство; предыдущие функции 0.1.20; фотометка; новые изменения 0.1.21.
- Подтверждено соответствие типов/размеров новых полей TPY; текущая карта содержит **233 поля, 153 скалярные настройки, 19 команд**, без несопоставленных элементов.
- Проверены **27 контрольных сумм** обязательных файлов, включая EXE, новые JSON/JS и турецкий язык. Они включены в обновлённый `Check_SCADA.ps1`.

## Проверенные сценарии 0.1.21

- Шесть отдельных температурных карточек; геометрия без наложений и целочисленные температуры.
- Фиксированная сетка 5×5; инженерные ячейки 4:5 и 5:5; отсутствие трёх удалённых кнопок.
- Все четыре страницы функционала, 62 строки, пояснения, исходные имена, подтверждение изменения, конфликт с HMI, отзыв роли и запрет записи при движении.
- Прямой HTTP-запрос оператора не позволяет записывать комплектацию. Один старый флаг с неподтверждённым физическим эффектом остаётся только для чтения.
- Диаметр клеевого вала, пределы 1–500 мм, реальное обратное чтение на имитаторе; отдельный импульс применения 1→0 с журналом снятия. Состояние ручного движения 6 не разрешает применение масштаба.
- Общая карточка двух новых параметров клея видна в обоих режимах; элементы страницы укладываются в 1024×600.
- Анимация пошаговой помощи меняет кадры после первого цикла при системном reduced-motion; прежние защёлка обучения, живой офсет и отсутствие повторных команд после потери связи сохранены.
- Задания вынесены из производства; оператор видит документ и все его вкладки. Импорт/выгрузка скрыты, запись через API защищена. Выгруженный инженером JSON совпадает с исходным заданием.
- Русский/английский и турецкий режим с оригинальными именами HMI; турецкие подписи и флаг. Часть старых SCADA-текстов имеет английский резервный перевод.
- Тёмная/классическая темы и масштабы 1024×600, 1920×1080, 3840×2160; отсутствие запросов к внешним ресурсам.

## Предел проверки

Выполнявшиеся записи адресованы только локальному имитатору ADS. Чтение реального `.AO_HotmeltRef`, фактическое применение NC-масштаба и физический расход клея нужно подтвердить на станке. Смысл неоднозначных исполнений Sedef Takma, Tavuk и Injet не подменён догадками — исходные имена сохранены в описаниях.
