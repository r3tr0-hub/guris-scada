# Продолжение разработки после 0.1.21

Текущие требования и изменения: `CHANGES_0_1_21_RU.md`. Карта всех 233 полей и 19 команд: `PARAMETER_BINDINGS.json`. Инженерные страницы OPSIYONLAR: `FUNCTIONALITY_EVIDENCE_0_1_21.json`; исходные фотографии — `reference/engineering-functionality`.

Фактическая архитектура этой сборки: **C11, локальный HTTP, HTML/CSS/JavaScript, SVG/Canvas, встроенная SQLite**. Совместимый запуск — Microsoft Edge kiosk. React/Tauri не являются зависимостями данного исходного кода. Windows EXE собирается из `src/main.c`; для Linux есть стенд `scada-test-host` и `build_linux_test.sh`.

ПЛК: Beckhoff/TwinCAT 2, ADS 801, TCP 48898. Соединение по умолчанию: IP 192.168.1.250, AMS Net ID 5.105.198.193.1.1. Данные и записи разрешаются по живым метаданным ADS: имя, тип, размер, версия символов и качество. Статические адреса Boot в доказательствах не являются адресами для сетевой записи.

Важные исходники:

- `src/fields.h`, `src/app.h` — объявления полей, цикл чтения, ограничения, роли, транзакции и обратное чтение.
- `src/commands.h` — ручные команды и устойчивое снятие импульсов/удержаний.
- `src/production.h`, `src/production_queue.h` — локальная история SQLite, задания, смены и причины простоев.
- `src/http.h` — доступ к данным и проверки прав в API.
- `ui/app.js` — интерфейс, фиксированная сетка, фотометка и экранный ввод.
- `ui/functionality.js` + `.json` — инженерные страницы и описания.
- `ui/production.js` — отдельные страницы производства и заданий.
- `ui/locales` — ru/en/tr; турецкий режим сохраняет оригинальные имена HMI, часть старых текстов имеет английский резервный перевод.

Принятые ограничения:

- Оператор просматривает задания, но импорт, выгрузка и действия учёта требуют инженера. История оператора ограничена его текущей сменой 08–20/20–08. Причины простоев пока предполагаются только по сигналам окончания лайнера и рулона; сервер причин/заданий ещё не подключён.
- Комплектация редактируется инженером только при состоянии 5/9 и auto=0. Устаревший флаг Dancer2 Direct Potance читается, но не записывается: его физическое действие не подтверждено.
- Диаметр энкодерного вала клея 1–500 мм доступен оператору на остановленной линии. Применение масштаба — отдельная штатная команда, при состоянии 5/9 и auto=0; не во время ручного движения (состояние 6).
- Обнуление всех трёх счётчиков доступно при любом состоянии машины, через штатные импульсы.
- Таймер возврата ленты 45 → 10 и восстановления контроля размотчика принадлежат процессу SCADA. Их существующие журналы и правила восстановления нужно сохранять при обновлении.
- «Мануалы» находятся на странице часов. «Задания» открываются только плашкой на главной; в «Производстве» вкладки заданий нет.

Основной источник восстановления HMI: `TCPLC_P_1.wbp`, SHA256 `60b2972ba194922a8abf3a2ef96d744e04dbab79bc1076b3fae93fe062bcddd6`, и соответствующий `CurrentPlc_1.tpy` из архива восстановления HMI. Для дальнейших исследований нужно использовать именно эти файлы либо заново проверить соответствие изменённой программы ПЛК. Полный первичный Boot в этот дистрибутив не вложен; сохранены точные доказательства уже выполненного разбора.

Проверки выполнены с локальным имитатором ADS. Данных о пусконаладке 0.1.21 на реальном станке ещё нет. Результаты — `VALIDATION_0_1_21_RU.md` и `BUILD_INFO.json`.
