# Guris SCADA 0.1.32 — масштаб иконок меню

Увеличены изображения: клей ×1,5, углы подачи ×2, нож ×1,3, лайнер примерно ×2,5 относительно 0.1.31. Для лайнера устранено перекрытие общих размеров старым более специфичным правилом CSS (46 вместо 90 px), затем уточнён viewBox. Остальные три изображения масштабированы viewBox. Размеры карточек, подписи, анимации и действия сохранены. Оригиналы SVG в assets не изменены.

Проверки: JSDOM/CSS; Linux backend через WSL и браузерная проверка меню в трёх темах и двух разрешениях, движения всех 12 иконок при потере связи, выключения/включения анимаций, включая reduced-motion; 10 тестов конфигурации и упаковки. Windows x64 собрана штатным скриптом Zig 0.13.0, ZIP проверен по CRC и SHA256. Полный backend/C-набор не повторялся: логика backend не изменялась. Физической приёмки и подключения к ПЛК не было. Update сохраняет рабочий connection.json и local.
