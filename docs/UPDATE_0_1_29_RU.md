# Guris SCADA 0.1.29 — иконки меню

Установлены предоставленные пользователем анимированные SVG v16 для 11 кнопок узлов: краевой контроль, температура, клей, воздушные трубки, углы подачи, продольный шов, нож, выкидные валы, лайнер, натяжение и размотчик. Расположение кнопок и переходы сохранены.

В архиве 13 SVG; все исходные файлы сохранены без изменения в `ui/assets/menu-v16/`. Их SHA256 сверены с CURRENT_SHA256.json комплекта. Для приёмного вала отдельной иконки нет: прежняя схема сохранена. `feeding.svg` и `continuous_seam.svg` пока не назначены кнопкам.

Иллюстрации встроены в HTML для работы без внешних ресурсов. Встроенные стили и анимации сохранены; служебные XML CDATA-маркеры убраны для HTML, корню добавлены класс и декоративные accessibility-атрибуты. Подписи кнопок остаются доступными на RU/EN/TR. Иллюстрации работают в меню при включённых анимациях независимо от состояния машины, при выходе из меню или скрытии окна приостанавливаются. Переключатель анимаций и prefers-reduced-motion учитываются. Иллюстрация не является показанием работы механизма.

Пакет Update не содержит runtime connection.json, аккаунтов и производственных баз. Распаковывать в установленную папку после закрытия SCADA. Существующие настройки подключения и local сохраняются.

## Проверки

- JSDOM/CSS: пройдены.
- WSL: сборка Linux backend и Playwright меню — 11 иконок, три реальные темы, 1024×600 и 1920×1080, границы карточек, движение за полный цикл, пауза при выключении анимаций, reduced-motion, отсутствие команд записи и ошибок JavaScript.
- Проверки упаковки и запуска с конфигурациями подключения: 10/10 пройдены (журнал build/validation/menu29.log).
- Windows x64: штатная сборка Zig 0.13.0; ZIP CRC и контрольные суммы проверены.
- Полный набор backend/C-тестов повторно не запускался: логика backend не менялась, обновлены только строки версии. Приёмка на реальном станке и физическом сенсорном экране не выполнялась.
