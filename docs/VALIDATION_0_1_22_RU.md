# Проверка SCADA 0.1.22

## Результаты

- 154 Python/API-теста — успешно, 260.551 с. Настоящий C-backend, локальный имитатор ADS, без станка.
- Семь C-наборов: часы временных режимов, запуск UI, bootstrap, время производства, причины простоев и смены — успешно.
- JSDOM и разбор CSS — успешно.
- Chromium без GPU: регрессия 0.1.21, полные привязки/команды и тест 0.1.22 — успешно. Все 28 описаний PERFORMANS проверены, ввод REAL/INT/DINT дошёл до ADS и подтвердился чтением; роль/остановка/потеря связи проверены.
- Четыре настоящих touch-свайпа через Chromium CDP: «Функционал» и «Производительность», в том числе начало жеста на кнопке настройки. Прокрутка работает; лишних записей и открытий клавиатуры нет.
- RU/EN/TR, тёмная и классическая тема; компоновка 1024×600, 1920×1080 и 3840×2160. Нет внешних запросов и ошибок JavaScript.
- Windows EXE: x86-64, GUI subsystem, только системные библиотеки Windows и Universal CRT. Zig 0.13, C11, предупреждений компилятора нет. Скрипт диагностики обновлён под контрольные суммы этой сборки, включая performance.json.

## Что проверялось для PERFORMANS

25 исходных вводов трёх страниц HMI сопоставлены с обработчиками ввода, типами TPY и местами использования в Boot. 22 новых символа дополнили существующую карту до 255 полей; четыре существующих ввода и два существующих показания использованы повторно без новых дублирующих привязок. Инженерный INT-предел длины и расчётный REAL-предел ввода оставлены раздельными.

Проверены все исходные диапазоны, целочисленные типы, конфликты с изменением из другого HMI, запрет записи в три показания, повторная проверка автоматического режима перед отправкой и запрет доступа оператора к новым инженерным настройкам. Открытие страниц и чтение описаний не записывают значения.

## Пределы проверки

Windows GUI и физический станок здесь не запускались. Подтверждение ADS-чтением проверяет значение переменной; физический результат движения, торможения или подачи материала проверяется на оборудовании. Три программных верхних предела дистанций, неизвестная единица раннего отвода и исходные Injet/Sepet Cozgu отмечены в документации без неподтверждённых трактовок.
