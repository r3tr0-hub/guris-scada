# Guris SCADA 0.1.27 — исправление оформления

Выпуск исправляет оформление рабочих экранов после перехода на пакеты тем. Отсутствие связи на домашнем ПК является ожидаемым состоянием. Отдельная домашняя редакция не создавалась.

## Причины и исправления

- В `themes.css` правила светлой палитры использовали основной тёмный текст как фон вкладок, клавиатуры и фильтров; неизвестные поля получали тёмный фон и малоконтрастные подписи. Эти правила удалены. Общие стили компонентов перенесены в `style.css`, файл тем содержит только смысловые цветовые роли и состояния, без размеров и `!important`.
- Пакеты задают согласованные пары поверхности и текста. Шапка, навигация, обычные и выбранные кнопки, инженерные плитки, поля, фактические значения, неизвестные данные и фокус имеют отдельные роли. Для основных пар трёх поставляемых тем проверен контраст не ниже 4.5:1. Переключение темы не меняет геометрию компонентов; декоративный переход цвета учитывается при снимках.
- Блокировка записи больше не приглушает целую плитку. Подписи и пояснения остаются читаемыми; неизвестные переключатели имеют нейтральный фон и прочерк, неизвестные входы — нейтральный полый индикатор. Маркер тонкой настройки скрывается до получения значения.
- Плитка «Нож» находилась за закрывающим тегом сетки. Теперь это обычная ячейка 2:3; базовые узлы, опции и намеренные пустые места сохранены.
- Canvas-иконки не рисовались, если неизвестен флаг комплектации. Поясняющая схема теперь видима и без связи; подтверждённо отсутствующие узлы по-прежнему скрываются. Исходные SVG не перерисовывались. Навигация при неизвестной комплектации открывает страницу просмотра, проверки записи сохраняются.
- В краевом контроле дополнительная строка физического режима не помещалась в прежнюю фиксированную высоту. Строки списка теперь растут по содержимому; список прокручивается, все элементы каждой карточки остаются внутри её рамки. Обрезанием содержимого дефект не маскируется.
- Общая компоновка шапки допускает более широкий текст часов; подписи навигации переносятся внутри кнопок, включая проверку с увеличенными буквами. Размер области нажатия не зависит от темы.

ADS-привязки, условия записи, алгоритмы, таймеры очистки и размотчика, производственная статистика не менялись. В backend обновлены только строки версии выпуска.

## Проверки

См. [отчёт проверки](VALIDATION_0_1_27_RU.md). Визуальные снимки получены из локального браузера и просмотрены; DOM-проверки дополнены проверкой PNG. Рабочая конфигурация и исходные материалы станка в Git не добавлены.

## Обновление

Архив `GurisSCADA_0_1_27_Update_Windows_x64.zip` — пакет **Update**. Закройте SCADA, сделайте резервную копию установленной папки и замените файлы приложения содержимым каталога внутри архива. Существующие `connection.json`, `local/`, журналы и свои `manuals/` сохраняются: их нет в пакете Update. Примеры мануалов находятся отдельно в `manual-examples/`.

Не переименовывайте отключённый `connection.example.json` в рабочий файл подключения при обновлении. Для отдельной локальной установки используйте отключённую конфигурацию разработки. После установки версия в «Опции SCADA» и диагностике должна быть 0.1.27.

На панели КП4 остаётся проверить физическое управление касанием, фактическую прокрутку и видимость текста при её настройках Windows/Edge. Это не выполненная приёмка на станке.
