# Guris SCADA — тест 0.1.10

Сборка с привязками по четырём архивам HMI/логгера от 15.10.2026. Подключены температуры, клей, лайнеры, натяжение, приёмный и выкидные валы, актуаторы, фотометка и раздув; для контроля края — состояния. Полная карта, пределы, исходные изменения и неподключённые элементы: **`docs/PARAMETER_BINDINGS_RU.md`** и **`docs/PARAMETER_BINDINGS.json`**. Всего 108 чтений, 77 новых или расширенных привязок, из них 53 с настройкой.

Сохранены киоск Edge и совместимый режим без GPU, цифровой PIN, анимации меню, целые температуры, уведомления сверху и таймер ускорения ленты. Windows x64 EXE собран и проверен на локальном имитаторе ADS; интерфейс проверен в Chromium без GPU. Новая версия ещё не проверена записью на реальном станке.

Полный план развития проекта: **`docs/ROADMAP_RU.md`**. Он описывает этапы, зависимости и критерии приёмки от текущей версии до локальной 1.0, интеграции VideoJet и сервера предприятия. Будущие номера версий в плане — предлагаемый состав, без обещания календарных сроков.

## Установка и обновление

1. Завершите старую SCADA через значок в трее → «Выход».
2. Распакуйте весь архив в новую папку на локальном диске. Не запускайте EXE внутри ZIP.
3. Если в предыдущей папке есть ваши `connection.json` и каталог `local`, перенесите их в новую папку. Не удаляйте журнал `local/cleaning.json`, пока возврат 10 не подтверждён.
4. Запускайте **Start_Compatibility.cmd**. Отключение GPU сохранено. Теперь открывается отдельный киоск Edge на весь экран с новым выделенным профилем `Edge_SCADA_Kiosk_1_Compatibility`. Ранее использованный профиль остаётся для отката. В киоске F11 не переключает полный экран; выход из окна — Alt+F4, завершение программы — «Выход» в SCADA или трее.
5. При первом входе инженера задайте свой цифровой пароль: минимум 6 цифр. После запуска приложение начинает работу с профилем оператора; сохранённый пароль продолжает действовать. Прежний буквенный пароль тоже принимается для входа и смены на цифровой.

Нужны Windows 10/11 **x64**, установленный Microsoft Edge и доступ к сети ПЛК. Python, Node.js, TwinCAT и .NET для обычного запуска не нужны. EXE предназначен для отдельного Windows-ПК, а не Windows CE панели. Папка программы должна разрешать запись журналов и локальных настроек.

По умолчанию: IP `192.168.1.250`, AMS Net ID `5.105.198.193.1.1`, ADS `801`, TCP `48898`. Должен сохраняться рабочий маршрут ADS с этого компьютера; SCADA не создаёт маршруты. Подключение настраивается после входа инженера: **Меню → Опции SCADA → Подключение к ПЛК**.

Закрытие окна оставляет приложение в трее. «Выход» завершает саму программу. При активном ускорении штатный выход сначала пытается вернуть 10; если связь отсутствует, задание возврата остаётся для следующего запуска.

## Изменения 0.1.10: параметры меню

- Шесть заданий и включений нагрева; пять фактических температур. Задания ограничены реальными окнами HMI: 490/300/300/300/485 °C, шестой канал 0…100%.
- В клее переключение режима подтверждает ПЛК. Три дистанции раздельные; подписи обычного и фотометочного режима соответствуют HMI. Ограничения по ширине проверяются ещё раз перед записью.
- Для каждого лайнера доступны растяжение, стоп-диаметр, автоостановка и показание диаметра. Натяжение −25…+25. Расчётная скорость приёмного вала доступна только для чтения.
- «Актуаторы» и «Фотометка» открываются из левой панели; поля и состояния связаны с ПЛК. Смещение фотометки — REAL в мм, без умножения на 10; шаговые кнопки 0,5 мм.
- Назначения температурных и исполнительных каналов сверяются с IDs HMI. При несоответствии или недоступности запись блокируется.
- Полный опрос разбит на пакеты до 64 символов. Счётчики/состояние сохраняют 100 мс, остальные поля — 500 мс. Ошибка отдельного параметра не превращает остальные значения в нули.

Кнопки ручного движения, импульсные команды сброса/обучения, неподтверждённые положения и подробный список аварий остаются недоступны. Причины и недостающие данные перечислены в отчёте. Нулевые значения похожих переменных не подставлены вместо неподтверждённых показаний.

## Изменения 0.1.9: панели Edge

Обычный и совместимый запуск используют `--kiosk` с `--edge-kiosk-type=fullscreen`, нулевым тайм-аутом бездействия и отдельным профилем SCADA. В совместимом режиме добавляется прежний `--disable-gpu`. Запуск `--app` / `--start-fullscreen` больше не используется для основного окна.

Киоск Edge использует приватное окно, где автозаполнение отключено; новые пароли браузер не сохраняет. Дополнительно у парольных полей задан `autocomplete="off"`. Для страницы установлены `translate="no"` и `notranslate`, а запускаемый процесс получает `--disable-features=Translate`. Собственный выбор Русский / English продолжает работать.

Кнопка HTML-полного экрана скрыта в киоске и не вызывает `requestFullscreen`: обычная плашка браузера о выходе из полного экрана не должна появляться из-за SCADA. После штатного завершения процесса запрашивается закрытие собственного окна киоска. Обычный диагностический браузер при выходе SCADA не закрывается.

Полное закрытие приватного окна завершает его cookie-сессию: при новом открытии инженер входит заново. Пароль в `local/accounts.json`, язык, оформление, подключение и таймер находятся в основном процессе/файлах SCADA. Закрытие окна не прерывает таймер основного процесса SCADA. Диагностический JSON по-прежнему можно сохранить из интерфейса.

Настройки реестра, политики Windows и личный профиль Edge приложение не меняет. **Start_Browser.cmd** и «Открыть в браузере» остаются диагностическими вариантами; на обычный сторонний браузер ограничения киоска не распространяются. При обновлении сначала закройте окно старой версии и завершите её процесс через трей.

Техническая основа режима: [Microsoft Edge kiosk mode](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-configure-kiosk-mode). Для киоска нужен поддерживающий этот режим Edge на Windows; это не установка Windows Assigned Access и не блокировка рабочего стола.

## Изменения 0.1.8

- Показания всех пяти температурных зон отображаются без дробной части: `443,5 → 443`, без округления до 444. Это только оформление; исходные REAL-значения в ПЛК, кэше и отчёте не меняются.

- Подключённый ADS в RUN показывает «Связь есть», как PLC. Код ADS в отчёте остаётся 5; остановленный ADS сохраняет жёлтое предупреждение, потеря соединения — красное «Нет связи».
- При выборе инженера открывается экранная цифровая клавиатура того же вида, что ввод параметров. Есть 0–9, удаление, очистка, отмена и ввод; пароль скрыт точками. Создание и смена требуют 6–128 цифр. Ведущий ноль сохраняется. Для старого буквенного пароля подходит физическая клавиатура ПК в этом же окне. После ввода окно переходит к повтору или следующему шагу, после последнего ввода выполняет вход/смену пароля.
- Оповещения, включая подтверждение обратным чтением, появляются сверху над рабочими полями. Они не перехватывают нажатия.
- Совместимый запуск Edge запрашивает полный экран. Сам `Start_Compatibility.cmd` и путь прежнего профиля сохранены.

Кнопки включения нагрева пока недоступны: подтверждены чтения температур, а точная PLC-команда включения/выключения каждой зоны не найдена. На странице это объяснено отдельной подписью. Уставка и фактическая температура не определяют состояние переключателя; массив `bHeatingPidPasif` не подменяет неизвестную команду нагрева. Подключение этих кнопок требует отдельного подтверждения сигналов.

## Иконка скорости шва

Иконка объединяет спидометр, часы и линию запайки. При включённой скорости шва и свежих положительных данных скорости станка ориентир равен половине заданной скорости выпуска:

- В пределах половины ±10 шт/мин стрелка стоит посередине и остаётся серой.
- Ниже диапазона стрелка смещается влево и становится приглушённо-красной.
- Выше диапазона стрелка смещается вправо и становится приглушённо-зелёной.

Это подсказка оператору: она не меняет задание и не запрещает другие допустимые значения. При автоматической работе движутся пунктир шва, стрелки часов и стрелка спидометра. При выключенной скорости шва, остановке, потере данных или отключённых анимациях движение прекращается. Источник скорости станка — прежнее подтверждённое задание выпуска, не новый измерительный канал.

## Динамическая иконка скорости

Приняты два независимых стандартных предела: 250 ударов ножа в минуту и 60 метров плёнки в минуту.

`Загрузка = max(скорость_шт_мин / 250, скорость_плёнки_м_мин / 60)`

Иконка показывает **ближайший предел**, а не среднее двух отношений. Внешняя дуга — нож, внутренняя — плёнка. Положение стрелки задаётся большей загрузкой; движение становится быстрее при приближении к пределу. Число может превышать 100%, но стрелка остаётся в конце шкалы. При остановке движение прекращается; оценка по заданию остаётся видна. Недоступные/некачественные данные не заменяются выдуманной скоростью.

Примеры: шаг 100 мм и 250 шт/мин дают около 25 м/мин — ограничивает нож; шаг 500 мм и 120 шт/мин дают 60 м/мин — ограничивает плёнка. При шаге 500 мм и 60 шт/мин большая загрузка равна 50%. При шаге 240 мм и 250 шт/мин одновременно достигаются оба предела.

В этой версии источник — подтверждённые **заданные** скорость выпуска и шаг, отображаемый как «Ширина пакета». Используется прежний расчёт интерфейса: `м/мин ≈ мм × шт/мин / 1000`; `м/с ≈ м/мин / 60`. Отдельный подтверждённый канал фактической скорости плёнки пока не подключён. Поэтому иконка не выдаёт расчёт за измерение. Эти ориентиры не меняют ограничения или настройки ПЛК.

## Холостая скорость: 10 / 45 / таймер

- Обычная уставка — **10**. Кнопка **«Ускорить · +60 с»** задаёт **45** и запускает таймер основного процесса SCADA.
- Следующее принятое нажатие добавляет 60 секунд к оставшемуся времени. Максимальный остаток — **180 секунд**: 170 + 60 = 180. Время между нажатиями расходуется.
- **«Вернуть 10»** досрочно отменяет ускорение. В конце таймера SCADA также задаёт 10 и подтверждает его обратным чтением.
- Режим доступен при свежих данных, ADS RUN, выключенном автоматическом режиме и состоянии 5, 6 или 9. Переход к автоматической работе, потеря свежих данных или изменение уставки другим интерфейсом прекращают ускорение и запрашивают возврат 10.
- Таймер работает без открытого окна, на любой странице и при смене профиля. Скорость и оставшееся время показывает страница «Лента»; активный режим также указан в подписи шапки.
- До повышения скорости на диск атомарно сохраняется задание возврата, привязанное к этому ПЛК. Ошибка сохранения блокирует повышение. Один идентификатор нажатия не учитывается повторно в пределах сохранённой истории запросов процесса.
- При потерянном ответе на повышение 45 повторно не отправляется: приложение переходит к возврату 10. Возврат 10 допускает повторную проверку и идемпотентное восстановление по свежим данным.
- После перезапуска SCADA незавершённое ускорение **не возобновляется**: сначала возвращается 10. На время незавершённого возврата нельзя выбрать другой ПЛК или отключить подключение из SCADA.
- Обычный числовой API допускает для этой уставки только 10. Бессрочно записать 45 или произвольное число через него нельзя. Первое включение приложения без журнала незавершённого ускорения автоматически в ПЛК ничего не записывает.

**Ограничение:** таймер находится в SCADA. Пока ПК выключен, процесс остановлен или связь оборвана, SCADA не может физически передать 10; до восстановления уставка может оставаться 45. Сохранённый журнал позволяет вернуть 10 после восстановления приложения и связи, но не обеспечивает независимый от ПК возврат. Это ограничение длительности режима, а не функция защиты от захвата движущимися ремнями; скорость 10 также не означает безопасную очистку. Оригинальный HMI и программа ПЛК не изменены.

Подробности: `plc-integration/BELT_CLEANING.md`.

## Локальные профили

Нажмите блок профиля слева от времени в шапке.

- **Оператор** — общий рабочий профиль без пароля. Доступны рабочие параметры, лента, таймер, подтверждённые обнуления и журнал.
- **Инженер** — вход по собственному паролю. При первом входе требуется повторить новый пароль. Заводского пароля нет. После входа появляется плашка **«Опции SCADA» над «Опции»** на странице «Меню».

Инженер меняет подключение к ПЛК и оформление SCADA. Доступ проверяется в основном приложении, а не только скрытием кнопок. Пароль сохраняется как PBKDF2-HMAC-SHA256 с индивидуальной случайной солью и 600000 итераций; открытый пароль не включается в отчёты или журналы. Сессия в HttpOnly cookie действует до 8 часов, смена пароля и выход отзывают прежнюю сессию. После нескольких неверных попыток действует задержка. Файл повреждённых профилей не подменяется новым через первичную настройку.

Пароль инженера находится в **`local/accounts.json` относительно папки EXE**. Файл содержит `version: 1`, `iterations: 600000`, `salt` (16 случайных байт, записанных 32 шестнадцатеричными символами) и `hash` (32 байта PBKDF2, записанные 64 шестнадцатеричными символами). Сам пароль или PIN в файл не записывается. При входе SCADA вычисляет хеш введённого пароля с сохранённой солью и сравнивает результат. Формат прежних файлов не изменён. Поэтому переносите каталог `local` при обновлении; смена пароля выполняется в «Опциях SCADA», без удаления профиля.

В «Опции SCADA» доступны оформление, подключение к ПЛК, диагностика, журнал, смена пароля и возврат к оператору. Пользователь и роль записываются в журнал операций. Это два общих локальных профиля, без списка персональных операторов и без обращения к серверу предприятия. Администратор Windows с правом изменения файлов приложения остаётся вне этой границы разделения ролей; резервную копию `local/accounts.json` следует хранить с ограниченным доступом.

Провайдер локальной авторизации, стабильные `userId`, роли и проверки разрешений выделены отдельно. План подключения сервера: `docs/LOCAL_AUTH.md`.

## Часы, календарь и оформление

Нажмите блок даты и времени в шапке: откроются крупные часы, календарь текущего месяца с понедельника, выделенное «сегодня» и прогресс текущей смены 08:00–20:00 / 20:00–08:00. Календарь обновляется при смене даты; используется локальное время Windows. Это индикатор времени, без расчёта выработки, выходных предприятия или учёта рабочего времени.

Фон — спокойный рисунок плёнки, перфорации и линии шва, выполненный внутри интерфейса без внешних ресурсов. Его можно отключить в инженерных опциях.

Снежинки появляются **только в декабре и январе**, если инженер включил соответствующую опцию и анимации. Частицы ограничены шапкой, не перехватывают нажатия и не закрывают рабочие поля. Даты берутся с этого ПК. Три настройки оформления и выбранный язык сохраняются в `local/scada_options.json`; прежние файлы с тремя настройками также читаются.

## Сохранённые рабочие функции

Все три счётчика используют движение на 5 пикселей за 150 мс при изменении качественных данных в одной сессии. Первое появление, переподключение и одинаковые ответы эффекта не запускают. Опция «Анимации» отключает эффект вместе с пульсом и движением иконки.

Два обнуления («Группы · готовые пачки», «Общий счётчик») требуют подтверждения, ADS RUN, свежих данных, состояния 5/9 и выключенной автоматической работы. Это только DINT 0 в конкретные символы `MAIN.diGrupAdet` и `MAIN.diToplamAdet`, с повторной проверкой описания и состояния и двумя обратными чтениями. Произвольный ввод счётчиков и неподтверждённые BOOL-команды HMI не используются. Сброс текущей пачки не добавлен. Прежнее значение восстановить через SCADA нельзя; поведение реального ПЛК ещё следует проверить на остановленном станке.

Рабочие привязки и типы находятся в `src/fields.h`. Для всех записей проверяются актуальное имя, тип, размер, адрес, права записи, поколение символов, свежесть исходных данных и разрешения режима. Числа в интерфейсе сохраняются прежними до подтверждения ПЛК; подтверждение закрывает ввод без дополнительной паузы. Обычные записи не повторяются автоматически при потере ответа. Пределы скорости/холостых ударов берутся из ПЛК. Тонкая настройка шага сохраняет преобразование знака.

Сохранён опрос 100 мс для счётчиков/состояния и 500 мс для остальных полей, без параллельных ADS-запросов и догоняющих очередей. Интерфейс получает локальный кэш через 100 мс, при записи — через 50 мс. «Актуаторы» и «Фотометка» подключены по новой карте. Подробные аварии и неизвестные команды остаются неподключёнными.

## Диагностика, файлы и сборка

`Run_SCADA_Check.cmd` создаёт диагностический отчёт запуска. Из интерфейса можно сохранить JSON-отчёт и просмотреть последние 32 записи; полный CSV — в `logs`. В отчёты не входят пароль, хеш пароля или cookie сессии.

Сохраняйте `connection.json` и каталог `local` при обновлении. `local/accounts.json` хранит хеш пароля, `local/scada_options.json` — оформление и язык, `local/cleaning.json` — незавершённое задание возврата. Не заменяйте файлы профилей/задания возврата во время работы приложения. При потере пароля восстановите свою резервную копию или обратитесь к инженеру, имеющему доступ к Windows; скрытого мастер-пароля нет.

Архив содержит исходники `src`, `ui`, `reference`, `tests`, документацию и Windows EXE. Для сборки: Zig 0.13.0, `build_windows.bat`. Для проверок на Linux нужны C11, pthreads, OpenSSL development и Python 3: `sh build_linux_test.sh`. Новые привязки также проверяются `python3 tests/test_parameter_bindings.py` и `python3 tests/run_browser.py test_bindings_browser.cjs`. Проверки интерфейса: Node.js, `jsdom`, `css-tree`; браузерные проверки — Playwright Chromium. Версии закреплены в `tests/package.json`: `npm install --prefix tests`, затем `node tests/test_ui.cjs`, `node tests/test_animation.cjs`; установите Chromium через `node tests/node_modules/playwright/cli.js install chromium` и запустите `python3 tests/run_browser.py`. Зависимости для разработки не нужны операторскому ПК.

Браузерные проверки меню и языков: `python3 tests/run_browser.py test_menu_browser.cjs`. Проверки правок 0.1.8, сенсорного PIN, целых температур, анимаций в готовности и уведомлений сверху: `python3 tests/run_browser.py test_polish_browser.cjs`. Файлы переводов и схем включены в проверку целостности `Check_SCADA.ps1`. Иконки из макета используют Lucide; лицензия включена в `LICENSE_LUCIDE.txt`. Для обычного запуска дополнительных библиотек не добавлено.

Проверки конфигурации запуска и подстановки режима в HTML выполняются нативными C-тестами из `build_linux_test.sh`. Браузерная проверка киоска: `python3 tests/run_browser.py test_kiosk_browser.cjs`. Она проверяет ветку интерфейса киоска, PIN, смену языка, скачивание отчёта и приватную сессию; панели Windows Edge не имитирует.

Проверки выполняются только с локальным имитатором ПЛК. Результаты этой сборки записаны в `BUILD_INFO.json`. Windows EXE собран перекрёстной компиляцией; запуск Windows GUI и работа новой версии с реальным станком здесь не проверены.
