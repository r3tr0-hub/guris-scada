# Изменения 0.1.19 — фотометка

- «Сброс фотометки» исправлен на фиксируемый режим «Обучение»: первое нажатие включает, повторное завершает. Состояние кнопки приходит из ПЛК, включая автоматическое снятие при пуске.
- Обучение передаётся явным значением 1/0 и подтверждается чтением флага. Повторное включение уже активного режима не сбрасывает отсчёт. Позднее завершение после автосброса не включает обучение заново.
- Смещение позиции обновляется в быстром цикле 100 мс. Во время обучения его считает ПЛК; ручная запись блокируется и на экране, и в нативном процессе.
- После обучения доступна коррекция стрелками по 0,5 мм и цифровым вводом, в том числе при автоматической работе. Предел штатного HMI сохранён: 0…текущая рабочая длина в миллиметрах.
- Photocell length отображается как измеренное среднее расстояние между метками, только для чтения.
- Уточнено назначение Photocell control window: допуск около ожидаемой метки, печать вне окна игнорируется. Подсказка поясняет, что увеличение расширяет окно распознавания.
- Восстановлена пошаговая помощь из утверждённого веб-макета: три этапа и анимации с плёнкой, фотодатчиком и SET. Добавлены фактический режим и живой офсет.
- Открытие/закрытие помощи не меняет ПЛК. При потере связи действия приостанавливаются, повторной отправки команд нет. SET на датчике подтверждает оператор.
- Сохранены русский/английский, тёмная/классическая темы, масштабирование до 4K и настройка анимаций. Пиктограммы страницы используют исходные векторные контуры.
- Обозначение версии в служебных заголовках и журнале запуска приведено к 0.1.19.

Boot и программа ПЛК не изменялись. Настройки подключения, локальные профили и история переносятся при обновлении по README_RU.md. Данные пользователя и пароли в архив не включены.

Подробные первичные привязки, ограничения и процедура: PHOTOMARK_RU.md.
