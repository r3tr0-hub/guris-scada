# Проверка SCADA 0.1.23

160 уникальных API-сценариев прошли: 154 существовавших и шесть новых для связанных показаний и общей чувствительности края. Для сценария с повторным прогоном учтён последний успешный результат; история попыток сохранена в native-results.json. Проверки используют настоящий C-backend и локальный ADS-имитатор, без станка.

- Тип/размер REAL, исходные пределы 0,1–10 мм, дробный ввод оператором, общее назначение, допустимые конфигурации 0/1/2/3/4 и блокировка неверной конфигурации.
- Повторная проверка конфигурации непосредственно перед записью, read-only metadata, конфликт со штатным HMI, потеря ACK без повторной записи.
- Три независимых фактических показания остаются только для чтения и связаны с правильными уставками.
- Семь C-наборов (временные режимы, запуск UI, bootstrap, производство/причины/смены) — успешно.
- JSDOM/CSS и Chromium без GPU — успешно. Регрессия интерфейса 0.1.21, общие привязки/команды, сценарии 0.1.22 и 0.1.23.
- 25 строк PERFORMANS с тремя вложенными фактами; одинаковая строка и координата по вертикали, белое задание и жёлтый факт в обеих темах. Независимые данные (110/107,5 и 2/2,4) и прочерк только у недоступного факта.
- Одна общая «Чувствительность» на странице края, цифровая клавиатура и подтверждённая дробная запись; потеря/возврат связи.
- Свайпы обоих списков, отсутствие случайных записей при прокрутке, все 28 описаний. RU/EN/TR, dark/classic, 1024×600, 1920×1080, 3840×2160.
- Оба EXE собраны для Windows x86-64, GUI subsystem. Проверены импорты системных библиотек Windows/Universal CRT, предупреждений компилятора нет. Контрольные суммы диагностики обновлены.

Windows GUI и физический станок здесь не запускались. Обратное чтение подтверждает значение переменной; физическую реакцию краевого контроля проверяют на оборудовании. При установке никакие уставки с фотографий не присваиваются ПЛК автоматически.
