# Guris SCADA 0.1.25

Постоянный локальный регистратор диагностики и один ZIP за последние 12 или 24 часа из «Опций SCADA». Запись работает в основном процессе при любом профиле, включая свёрнутый в трей интерфейс.

Отдельная SQLite-БД и поток, ограниченная очередь, качество/возраст сигналов, три счётчика, управление размотчиком и таймеры, аварии, операции и результаты обратного чтения, сеансы, ошибки хранения и интерфейса. Каждые 30 секунд — снимок уже полученных параметров. Экспорт готовится в фоне и передаётся небольшими порциями. Дополнительного ADS-опроса нет.

Отчёт JSON получил схему 2, точное время, идентификатор сеанса/исходников и сведения о среде. В сборку включён стандартный Python-скрипт для предварительного разбора архива. Работа самой SCADA Python не требует. SQLite и miniz встроены в EXE.

Политика назначения причин простоев остаётся v1. Журнал фиксирует её решения, включая известное закрытие эпизода при коротком доматывании. Регулировки, роли, подписки инженерки и правила выполнения PLC-команд сохранены.
