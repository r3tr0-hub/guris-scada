# Guris SCADA 0.1.17 · Мануалы

На левой панели под Фотометкой появилась страница Мануалы. Её иконка — открытая книга с коротким перелистыванием при нажатии; длительность до 1,82 с, общий таймер реакции — 2,2 с. Настройка «Анимации» отключает этот эффект вместе с остальными декоративными анимациями.

Одна инструкция — отдельная папка: `manuals/имя-папки/index.md`. Фотографии лежат рядом или в подпапке `images`. Названия файлов и папок могут содержать русские буквы и пробелы. Текст сохраняется в UTF-8.

Список обновляется автоматически примерно раз в 3 секунды, пока открыта страница. Добавление, изменение или удаление гайдов не требует перезапуска SCADA. Есть поиск по названиям/описаниям/разделам и фильтр раздела. Название и описание извлекаются из первого заголовка/абзаца либо из необязательных метаданных title, summary, category, order.

Гайд открывается внутри SCADA с прокруткой. Поддерживаются заголовки, списки и вложенные списки, текстовые флажки, выделение, цитаты, таблицы, код, локальные фотографии и ссылки между гайдами. При изменении открытого гайда появляется кнопка обновления; текст не заменяется посреди чтения автоматически.

Фото открывается крупным планом, масштабируется от размера по окну до 400%, закрывается кнопкой или Escape. Поддерживаются JPG/JPEG, PNG, WebP. Отсутствующее фото показывает сообщение внутри гайда и не блокирует интерфейс.

Включены два примера с предоставленными ранее иллюстрациями HMI:

1. «Как сделать понятное фото для инструкции» — оформление, подписи, списки, таблица и заметки.
2. «Как добавить свой мануал» — структура папки, Markdown, метаданные, фотографии и обновление.

Пределы: 128 гайдов; index.md до 64 КБ; каждое фото до 16 МБ. Встроенный HTML показывается текстом, внешние картинки не загружаются. Каталог читается только внутри manuals; произвольные пути, ссылки на каталоги/файлы вне него и альтернативные потоки Windows не открываются. Мануалы не вызывают команды ПЛК и доступны при отсутствии ADS-связи.

Разбор Markdown выполняет включённый в ui парсер Marked 17.0.5 (MIT). Из его токенов создаются обычные элементы DOM; авторский HTML не вставляется через innerHTML. Для работы сборки не нужны Node.js/Python и интернет. Лицензия: ui/vendor/MARKED_LICENSE.md.

При обновлении сохраняйте собственные папки из manuals вместе с прежними connection.json и каталогом local. Не заменяйте свои отредактированные гайды неизменёнными примерами из нового архива. Начальная инструкция находится в manuals/README_RU.md.

Обмен ADS, привязки станка, сбросы, таймеры и авторизация версии 0.1.16 сохранены. Реальный Windows GUI и ПЛК станка здесь не запускались; проверка выполняется на локальном имитаторе и в браузере.
