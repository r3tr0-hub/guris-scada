Справочник из текущего каталога интерфейса. Полные доказательства обработчиков и отпечатки исходных фотографий: `reference/engineering-0.1.24-bindings.json`. Исходные пределы передаются без изменения единиц; при отсутствии границ используется исходный тип ПЛК.



## Подающий вал · ANA MERDANE



Фото: enginer_IMG_20261009_193734.jpg.



| Параметр | Исходное имя | Тип | Доступ / диапазон | Переменная |
|---|---|---|---|---|
| Диаметр подающего вала | Roller diameter | REAL | 50.0…120.0 | `.stKaliciData.sRecipeData.rMerdaneCap1` |
| Передаточное отношение подачи | Roller reduction | REAL | 1.0…5.0 | `.stKaliciData.sRecipeData.rMerdane1Reduksiyon` |
| Скорость обратного хода | Roller Backward speed | REAL | 1.0…120.0 | `.stKaliciData.sRecipeData.rMerdaneGeriPosHizi` |
| Скорость ручной протяжки | Jog speed | REAL | 1.0…60.0 | `.stKaliciData.sRecipeData.rMerdaneJogHiz` |
| Длина обратного хода | Backward position length | REAL | 0.0…100.0 | `.stKaliciData.sRecipeData.rMerdaneGeriPosMesafe` |
| Угол начала обратного хода | Backward position angle | REAL | 0.0…180.0 | `.stKaliciData.sRecipeData.rMerdaneGeriAci` |
| Разгон при ручной протяжке | Cylender jog Acc time (s) | REAL | 0.1…20.0 | `.stKaliciData.rMerdaneJogAcc` |
| Задержка старта подачи | Start time | DINT | 1.0…10000.0 | `.stKaliciData.sRecipeData.diStartBeklemeSure` |
| Максимальная скорость подачи | Merdane Maks.Hiz (mmsn) | REAL | 3000.0…8000.0 | `.stKaliciData.rMaxMerdaneHiz` |
| Применить масштаб · подающий вал | Kaydet | BOOL | команда с подтверждением | `.sMerdane1.bWriteSF` |



**Диаметр подающего вала.** Рабочий диаметр вала для пересчёта оборотов в длину подачи. После изменения примените масштаб привода.

**Передаточное отношение подачи.** Коэффициент передачи основного подающего вала. После изменения примените масштаб привода кнопкой «Применить».

**Скорость обратного хода.** Скорость обратного позиционирования подающего вала.

**Скорость ручной протяжки.** Скорость подающего вала при ручном Jog. Изменение числа не запускает движение.

**Длина обратного хода.** Расстояние обратного позиционирования плёнки подающим валом.

**Угол начала обратного хода.** Фаза ножа, в которой подающий вал начинает обратное позиционирование.

**Разгон при ручной протяжке.** Время разгона подающего вала при удержании ручной кнопки Jog.

**Задержка старта подачи.** Задержка запуска подающего вала в начале рабочего цикла.

**Максимальная скорость подачи.** Предельная линейная скорость подающего вала. Это калибровочное ограничение привода, а не задание скорости выпуска.

**Применить масштаб · подающий вал.** Передаёт запрос пересчёта масштаба указанной оси после изменения диаметра или передачи. Запрос снимается SCADA после импульса; подтверждение передачи не означает окончания внутреннего пересчёта ПЛК.

**Смещение синхронизации ножа.** Фазовая поправка ножа относительно синхронного цикла. Рядом отображается фактический угол ножа.

**Зубьев шестерни сервопривода ножа.** Число зубьев ведущей шестерни сервопривода ножа.

**Зубьев ведомой шестерни ножа.** Число зубьев механической передачи ножа. После изменения примените масштаб оси.

**Угловое окно шва.** Угловой интервал синхронного участка ножа при сварке.

**Скорость ручного проворота ножа.** Задание скорости Jog ножа в единицах штатного HMI. Само редактирование не включает ручной ход.

**Коэффициент разгона Moonstep.** Коэффициент профиля разгона ножа в режиме скорости шва.

**Коэффициент замедления Moonstep.** Коэффициент профиля замедления ножа в режиме скорости шва.

**Шаг изменения скорости ножа.** Приращение задания скорости ножа при ступенчатом регулировании.

**Начальная скорость линии.** Скорость, с которой система начинает автоматическую работу.

**Максимальное ускорение ножа.** Ограничение ускорения ножа в масштабе штатного HMI. Это не начальная скорость линии.

**Максимальная угловая скорость ножа.** Предельная угловая скорость оси ножа. В штатном HMI это отдельное поле Cene Maks.Hiz.

**Ручное задание трансформатора ножа.** Ручное опорное значение управления трансформатором ножа.

**Начальная скорость шва.** Начальная скорость режима шва, используемая при выходе на рабочий режим ножа.

**Применить масштаб · нож.** Передаёт запрос пересчёта масштаба указанной оси после изменения диаметра или передачи. Запрос снимается SCADA после импульса; подтверждение передачи не означает окончания внутреннего пересчёта ПЛК.

**Фактический угол ножа.** Фактическое показание ПЛК: Фактический угол ножа. Доступно только для чтения.
