# Производственные задания

Сам каталог `production` не сканируется и не активирует примеры. Примеры лежат в `examples`. Для загрузки: инженер → Производство → Загрузить задание. Начало учёта — отдельное подтверждаемое действие оператора.

Настоящее задание выгружайте из `tools/Constructor_TZ_SCADA.html` кнопкой «Задание для SCADA». Требуются номер задания, номер/редакция ТЗ, тираж, дата и утверждающий. Формат — UTF-8 JSON, до 128 КиБ, без повторяющихся ключей; дополнительные текстовые поля до 8192 байт. Ограничения коротких идентификаторов и подписей в реализации заданы в UTF-8 байтах.

Полная инструкция: ../docs/PRODUCTION_RU.md. JSON Schema: job.schema.json. Справочники и расчётные величины передаются снимком и в SCADA заново не пересчитываются.
